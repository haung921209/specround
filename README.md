# specround

Spec review rounds for humans and AI agents — comments that survive revisions,
edits that become suggestion diffs, and every disposition recorded in a
git-native ledger. No server.

사람과 에이전트가 스펙 문서를 사이에 두고 리뷰를 도는 도구. 코멘트는 개정을 넘어
살아남고(앵커), 편집은 제안 diff 로 접수되고, 모든 처분이 repo 안 원장에 남는다.
